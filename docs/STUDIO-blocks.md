# Studio: blocks and groups

Read this when a link sent you to Agents -> Cast's blocks (a tier with its purpose, a workflow square with the agents inside it) or Live's groups: both went in 3.6.0.0.

Part of [Halo Studio](STUDIO.md), which lists every part; the Agents section itself is [Studio: Agents](STUDIO-agents.md).

## Blocks: the tiers and the squares on one board (3.3.16.3)

Went in 3.6.0.0 R5 with Cast. A workflow is steps of your agents on Agents -> 2 · Workflows
([STUDIO-workflows.md](STUDIO-workflows.md)); who main hands work to, and when, is a line on Agents -> 3 · Map
([STUDIO-map.md](STUDIO-map.md)). `halo workflows new <name> --from <starter>` copies a starter (`halo workflows
list` names them).

## Composing: the line, the library, the drags (3.3.16.3 part 2)

Went with the blocks. Dragging an agent or a workflow onto the Map, and its When card, are
[STUDIO-map.md](STUDIO-map.md#adding).

## Live in groups (3.3.16.3)

Went with Live. On the lit Map a helper an agent started shows under its box (`+N under it`), and the drawer lists them.
